# 👋 About the Portfolio

Welcome to my **WebForge Portfolio** — a personal portfolio website created to showcase my journey, skills, projects, achievements, certifications, and interest in technology.

This portfolio was developed as part of my participation in **WebForge**, where I explored web development, creative UI design, and interactive website development.

The portfolio represents my learning journey as a **BCA student at CHARUSAT** and my continuous effort to improve my technical and creative skills.
